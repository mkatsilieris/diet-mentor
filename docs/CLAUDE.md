# Σύνδεση του Claude με το Diet Mentor

Με αυτή τη σύνδεση μιλάς στο Claude και εκείνο κάνει για σένα ό,τι θα έκανες μέσα στην εφαρμογή:
γράφει τι έφαγες, καταχωρεί ζυγίσεις, σου λέει πώς πας, ξεκινά ή τελειώνει μια δίαιτα, αλλάζει το πλάνο
γευμάτων και τις ειδοποιήσεις.

Η ρύθμιση γίνεται μία φορά και θέλει περίπου 5 λεπτά.

## Τι χρειάζεσαι

- Λογαριασμό στο Diet Mentor: <https://diet.ninblack.com>
- **Claude Code** (τερματικό ή επέκταση VS Code) ή **Claude Desktop**

Η σύνδεση δεν δουλεύει ακόμη από το claude.ai στον browser ούτε από την εφαρμογή Claude στο κινητό.

## Βήμα 1: Φτιάξε το προσωπικό σου token

Το token είναι ένα κλειδί που δείχνει στο Diet Mentor ότι το Claude ενεργεί για λογαριασμό σου. Δεν
δίνεις ποτέ στο Claude τον κωδικό σου.

1. Άνοιξε το Diet Mentor και πήγαινε **Προφίλ → Σύνδεση με Claude**.
2. Γράψε ένα όνομα για να θυμάσαι πού το έβαλες, π.χ. «Claude στο laptop».
3. Διάλεξε τι επιτρέπεται:
   - **Ανάγνωση και αλλαγές**: το Claude βλέπει και γράφει.
   - **Μόνο ανάγνωση**: το Claude βλέπει την πρόοδό σου αλλά δεν αλλάζει τίποτα.
4. Διάλεξε διάρκεια (30 ημέρες, 90 ημέρες ή 1 χρόνος). Όταν λήξει, φτιάχνεις καινούργιο.
5. Πάτα **Δημιουργία token** και αντίγραψέ το αμέσως. Ξεκινά με `dmt_` και εμφανίζεται **μόνο μία φορά**.

## Βήμα 2: Πρόσθεσέ το στο Claude

### Claude Code

Μετά τη δημιουργία του token, το κουμπί **Αντιγραφή εντολής για Claude Code** σου δίνει έτοιμη την εντολή.
Επικόλλησέ τη σε ένα τερματικό. Αν θες να τη γράψεις μόνος σου, είναι αυτή, με το δικό σου token στη θέση
του `dmt_...`:

```bash
claude mcp add --transport http --scope user diet-mentor https://diet.ninblack.com/api/mcp --header "x-api-key: dmt_..."
```

Το `--scope user` κάνει τη σύνδεση διαθέσιμη σε όλους τους φακέλους σου, όχι μόνο στον τρέχοντα.

Έλεγχος: τρέξε `claude mcp list`. Το `diet-mentor` πρέπει να εμφανίζεται ως συνδεδεμένο. Μέσα στο Claude
Code το ίδιο φαίνεται με `/mcp`.

### Claude Desktop

Το Claude Desktop χρειάζεται ένα μικρό βοηθητικό πρόγραμμα (`mcp-remote`) που τρέχει με το
[Node.js](https://nodejs.org) (έκδοση 18 ή νεότερη). Εγκατάστησε πρώτα το Node.js αν δεν το έχεις.

1. Στο Claude Desktop: **Settings → Developer → Edit Config**. Ανοίγει το αρχείο `claude_desktop_config.json`.
2. Πρόσθεσε το παρακάτω, με το δικό σου token στη θέση του `dmt_...`. Αν το αρχείο έχει ήδη ενότητα
   `mcpServers`, βάλε μέσα της μόνο το κομμάτι `"diet-mentor": { ... }`.

```json
{
  "mcpServers": {
    "diet-mentor": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://diet.ninblack.com/api/mcp",
        "--header",
        "x-api-key:${DIET_MENTOR_KEY}"
      ],
      "env": {
        "DIET_MENTOR_KEY": "dmt_..."
      }
    }
  }
}
```

3. Κλείσε εντελώς το Claude Desktop και άνοιξέ το ξανά. Το `diet-mentor` εμφανίζεται στα εργαλεία της
   συνομιλίας.

## Βήμα 3: Δοκίμασέ το

Γράψε στο Claude κάτι σαν:

- «Πώς πάω σήμερα με τις θερμίδες;»
- «Γράψε ότι έφαγα γιαούρτι με μέλι, 220 θερμίδες, στις 10:30.»
- «Ζυγίστηκα 84,6 σήμερα.»
- «Τι έφαγα χθες; Διόρθωσε το μεσημεριανό σε 700 θερμίδες.»
- «Πόσο έλλειμμα είχα αυτή την εβδομάδα και πόσο λίπος έχασα;»
- «Ξεκίνα δίαιτα με μισό κιλό την εβδομάδα για 60 μέρες, με στόχο τα 80 κιλά.»
- «Βάλε υπενθυμίσεις γευμάτων στις 08:30, 14:00 και 20:30.»

## Τι μπορεί να κάνει το Claude

| Περιοχή | Βλέπει | Αλλάζει (μόνο με token «Ανάγνωση και αλλαγές») |
|---|---|---|
| Σύνοψη | Θερμίδες σήμερα, στόχος, ρυθμός ημέρας, ελλείμματα, γλυκογόνο, σερί, ορόσημα | |
| Ημερολόγιο φαγητού | Καταχωρίσεις μιας μέρας, τα φαγητά που γράφεις συχνά | Νέα καταχώριση, διόρθωση, διαγραφή |
| Σώμα | Στοιχεία σώματος, ζυγίσεις | Αλλαγή στοιχείων, νέα ζύγιση, διαγραφή ζύγισης |
| Δίαιτες | Όλες οι δίαιτες με τα στατιστικά τους | Έναρξη, αλλαγή, τέλος, διαγραφή |
| Πλάνο γευμάτων | Γεύματα, ώρες, ποσοστά | Αλλαγή πλάνου |
| Ειδοποιήσεις | Ρυθμίσεις, ιστορικό | Αλλαγή ρυθμίσεων, δοκιμαστική ειδοποίηση |
| Λογαριασμός | Όνομα, email | Αλλαγή ονόματος |

Τρία πράγματα γίνονται **μόνο μέσα από την εφαρμογή** και όχι από το Claude: η αλλαγή κωδικού, η δημιουργία
ή ανάκληση tokens, και η ενεργοποίηση ειδοποιήσεων push σε μια συσκευή.

## Ασφάλεια

Πώς προστατεύεται η σύνδεση:

- Η επικοινωνία είναι κρυπτογραφημένη (https) από το Claude μέχρι το Diet Mentor.
- Το Claude δεν μαθαίνει ποτέ τον κωδικό σου. Έχει μόνο το token.
- Το token δίνει πρόσβαση **μόνο στα δικά σου δεδομένα**.
- Το Diet Mentor δεν αποθηκεύει το ίδιο το token αλλά ένα μη αναστρέψιμο αποτύπωμά του. Γι' αυτό δεν μπορεί
  να σου το ξαναδείξει.
- Κάθε token λήγει μόνο του και ανακαλείται όποτε θες. Η ανάκληση ισχύει αμέσως.
- Πολλές λάθος προσπάθειες από την ίδια διεύθυνση μπλοκάρονται για 15 λεπτά.
- Κάθε ενέργεια του Claude καταγράφεται στο Diet Mentor (ποιο token, ποια ενέργεια, πότε).

Τι να προσέχεις εσύ:

- Φέρσου στο token όπως σε έναν κωδικό. Μην το στέλνεις σε μηνύματα ή email και μην το ανεβάζεις σε
  κοινόχρηστους φακέλους ή σε git.
- Χρησιμοποίησε **ένα token ανά συσκευή**. Αν χάσεις μια συσκευή, ανακαλείς μόνο το δικό της.
- Αν θες το Claude μόνο να σε ενημερώνει, διάλεξε **Μόνο ανάγνωση**.
- Αν υποψιαστείς ότι το token το είδε κάποιος άλλος: **Προφίλ → Σύνδεση με Claude → Ανάκληση** και φτιάξε
  καινούργιο.
- Στο **Προφίλ → Σύνδεση με Claude** βλέπεις πότε χρησιμοποιήθηκε τελευταία φορά κάθε token. Αν δεις χρήση
  που δεν έκανες εσύ, ανακάλεσέ το.
- Το Claude έχει οδηγία να σου ζητά επιβεβαίωση πριν διαγράψει κάτι ή ξεκινήσει και τελειώσει δίαιτα.
  Διάβασε τι πρόκειται να κάνει πριν απαντήσεις «ναι». Οι διαγραφές δεν αναιρούνται.

## Αν κάτι δεν δουλεύει

| Τι βλέπεις | Τι σημαίνει | Τι κάνεις |
|---|---|---|
| `401` ή «Το token δεν είναι έγκυρο, έχει λήξει ή έχει ανακληθεί» | Το token γράφτηκε λάθος, έληξε ή ανακλήθηκε | Φτιάξε νέο token και ξαναπρόσθεσε τη σύνδεση |
| «This token is read-only» | Το token είναι «Μόνο ανάγνωση» | Φτιάξε token «Ανάγνωση και αλλαγές» |
| `429` | Πολλές λάθος προσπάθειες ή πάρα πολλές κλήσεις | Περίμενε 15 λεπτά και έλεγξε το token |
| Σελίδα σύνδεσης Cloudflare αντί για απάντηση | Ο διαχειριστής δεν έχει ανοίξει ακόμη τη σύνδεση για το Claude | Ζήτησέ του να τρέξει τη ρύθμιση «Claude» του README |
| Το `diet-mentor` δεν εμφανίζεται στο Claude Desktop | Το αρχείο ρυθμίσεων έχει λάθος ή λείπει το Node.js | Έλεγξε τα κόμματα και τις αγκύλες του JSON, εγκατάστησε το Node.js, κάνε επανεκκίνηση |

Για να αφαιρέσεις τη σύνδεση από το Claude Code: `claude mcp remove diet-mentor`. Μετά ανακάλεσε και το
token από την εφαρμογή.
