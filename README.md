# Diet Mentor – ψηφιακός μέντορας αδυνατίσματος

Self-hosted εφαρμογή που υπολογίζει πόσες θερμίδες χρειάζεσαι για να μείνεις στα ίδια κιλά και για να χάνεις,
κρατά ημερολόγιο φαγητού, μετρά το έλλειμμα ανά ημέρα, εβδομάδα και μήνα λαμβάνοντας υπόψη το γλυκογόνο, και
οργανώνει τις δίαιτες σε sessions με αρχή και τέλος. Χτισμένη πάνω στον ίδιο σκελετό με το
[Bill Split](../bill-split) και το [Weather Alert](../weather-alert): ίδιο login (email & κωδικός ή Cloudflare
Access), React PWA, Node API, PostgreSQL, docker compose για Raspberry Pi, ίδιο deploy.

## Λειτουργίες

- **Σώμα**: φύλο, ημερομηνία γέννησης (από εκεί η ηλικία), ύψος, δραστηριότητα και ζυγίσεις. Από αυτά βγαίνουν ο
  βασικός μεταβολισμός, οι θερμίδες συντήρησης και πίνακας «τι τρως για να χάνεις 0,25 / 0,5 / 0,75 / 1 kg την εβδομάδα».
  Κάθε νέα ζύγιση ξαναϋπολογίζει τις θερμίδες από εκείνη τη μέρα και μετά.
- **Σήμερα**: τι έφαγες, πόσες θερμίδες, τι ώρα (προαιρετικά και υδατάνθρακες). Δακτύλιος «έφαγες / στόχος /
  απομένουν», τα δικά σου φαγητά ξανά με ένα πάτημα, διόρθωση και διαγραφή, πλοήγηση σε προηγούμενες μέρες.
- **Πρόοδος**: έλλειμμα χθες / εβδομάδας / μήνα / 30 ημερών, γράφημα ανά ημέρα, πίνακες ανά εβδομάδα και ανά μήνα,
  απόθεμα γλυκογόνου, ζυγίσεις απέναντι στο αναμενόμενο βάρος.
- **Δίαιτες**: ξεκινάς δίαιτα με ρυθμό, διάρκεια σε μέρες και (προαιρετικά) βάρος-στόχο· όσο τρέχει, ο ημερήσιος
  στόχος είναι συντήρηση − έλλειμμα. Την τελειώνεις όποτε θες και μένει στο ιστορικό με το τι πέτυχες. Μία τη φορά.
- **Κίνητρο**: σερί ημερών καταγραφής και ημερών μέσα στον στόχο (με ρεκόρ), συνολικό έλλειμμα και λίπος, ορόσημα,
  πρόβλεψη ημερομηνίας για το βάρος-στόχο, και ο «μέντορας»: ως 4 σύντομα σχόλια της ημέρας.
- **Ειδοποιήσεις push** (Προφίλ → Ειδοποιήσεις): υπενθυμίσεις γευμάτων στις ώρες που ορίζεις (μόνο αν δεν έχεις
  γράψει κάτι από την προηγούμενη), «φάε κάτι» όταν περάσουν πολλές ώρες (προεπιλογή 4, από 08:00 ως 21:30) από το
  τελευταίο γεύμα του ημερολογίου, πριν η πείνα φέρει υπερφαγία (ως δύο φορές ανά κενό, με 90 λεπτά διαφορά· όχι όταν
  ο στόχος της μέρας έχει καλυφθεί· καταχωρίσεις κάτω από 50 kcal δεν μετράνε για γεύμα), μία φορά τη μέρα πώς πήγε η χθεσινή, νέα ορόσημα και σταθμοί της δίαιτας, και κάθε
  Δευτέρα η σύνοψη της εβδομάδας. Οι κανόνες είναι στο `api/src/lib/nudges.ts`, ο scheduler στο `api/src/reminders.ts`.
- Mobile-first UI στα ελληνικά, light/dark mode, PWA. Κάθε λογαριασμός βλέπει μόνο τα δικά του.

## Πώς υπολογίζει

Όλη η λογική είναι καθαρές συναρτήσεις με tests: `api/src/lib/energy.ts` (φυσιολογία) και `api/src/lib/summary.ts`
(ό,τι δείχνει η εφαρμογή, από τέσσερις λίστες και τη σημερινή ημερομηνία).

| Τι | Πώς |
|---|---|
| Βασικός μεταβολισμός | Mifflin-St Jeor: `10·kg + 6,25·cm − 5·ηλικία + 5` (άνδρας) ή `− 161` (γυναίκα) |
| Συντήρηση | βασικός × 1,2 / 1,375 / 1,55 / 1,725 / 1,9 ανάλογα με τη δραστηριότητα |
| Στόχος δίαιτας | συντήρηση − `ρυθμός · 7700 / 7`, ποτέ κάτω από 1.200 kcal (γυναίκα) / 1.500 kcal (άνδρας) |
| Έλλειμμα ημέρας | συντήρηση εκείνης της μέρας − θερμίδες που γράφτηκαν |
| Λίπος | `(έλλειμμα − 4 kcal × g γλυκογόνου που χάθηκαν) / 7700` |

Δύο κανόνες που κρατούν τα νούμερα τίμια:

- **Μέρα χωρίς καταχωρίσεις = άγνωστη**, όχι νηστεία. Δεν μπαίνει σε κανένα άθροισμα.
- **Η σημερινή μέρα φαίνεται αλλά δεν αθροίζεται** μέχρι να τελειώσει (αλλιώς το πρωί θα έδειχνε τεράστιο έλλειμμα).

### Γλυκογόνο

Το σώμα κρατά περίπου μισό κιλό γλυκογόνο και κάθε γραμμάριο δένει ~3 g νερό. Σε έλλειμμα το απόθεμα αδειάζει σε
λίγες μέρες (η ζυγαριά πέφτει γρήγορα, χωρίς να είναι λίπος) και ξαναγεμίζει μόλις φας κανονικά. Το μοντέλο:

1. Χωρητικότητα = 9 g ανά kg άλιπης μάζας (τύπος Boer), π.χ. ~570 g για άνδρα 85 kg / 180 cm.
2. Κάθε μέρα έχει ένα «σημείο ισορροπίας»: `1 − 1,3·(1 − λόγος)`, μεταξύ 30% και 100%. Ο λόγος είναι
   θερμίδες / συντήρηση, ή υδατάνθρακες / (45% της συντήρησης) όταν **όλες** οι καταχωρίσεις της μέρας έχουν υδατάνθρακες.
3. Το απόθεμα κινείται προς την ισορροπία κατά 50% τη μέρα όταν αδειάζει και 70% όταν γεμίζει.
4. Τα g που χάθηκαν × 4 kcal αφαιρούνται από το έλλειμμα πριν γίνει λίπος, και × 4 (γλυκογόνο + νερό) είναι η
   επίδρασή τους στη ζυγαριά. «Αναμενόμενο βάρος» = αρχικό − λίπος ± γλυκογόνο.

Είναι εκτίμηση, όχι μέτρηση. Οι σταθερές είναι στην κορυφή του `energy.ts`.

Η εφαρμογή απευθύνεται σε ενήλικες και δεν αντικαθιστά γιατρό ή διαιτολόγο.

## Αρχιτεκτονική

```
web/   React + Vite + TypeScript (PWA), σερβίρεται από nginx που κάνει reverse proxy το /api
api/   Node 22 + Express 5 + TypeScript, JWT auth, bcrypt, zod, web-push, scheduler ειδοποιήσεων (ανά λεπτό)
db     PostgreSQL 16 (schema δημιουργείται αυτόματα στην εκκίνηση του api)
```

Οι μέρες αποθηκεύονται ως ημερολογιακές ημερομηνίες (`DATE`) και το «σήμερα» ορίζεται από το `DISPLAY_TZ`.

## Γρήγορη εκκίνηση (τοπικά ή σε Raspberry Pi)

```bash
cd diet-mentor
cp .env.example .env
# Άλλαξε τουλάχιστον το JWT_SECRET (π.χ. openssl rand -hex 32) και το APP_URL
docker compose up -d --build
```

Άνοιξε `http://<ip-του-server>:8082` (8082 για να συνυπάρχει με το Bill Split στην 8080 και το Weather Alert στην
8081), φτιάξε λογαριασμό, πήγαινε **Σώμα** και συμπλήρωσε τα στοιχεία σου.

| Μεταβλητή | Περιγραφή |
|---|---|
| `WEB_PORT` | Θύρα της εφαρμογής (default 8082) |
| `APP_URL` | Δημόσιο URL (σύνδεσμοι επαναφοράς κωδικού, μόνο επιτρεπτό CORS origin) |
| `JWT_SECRET` | Μυστικό υπογραφής των tokens σύνδεσης. **Άλλαξέ το.** |
| `DISPLAY_TZ` | Ζώνη ώρας που ορίζει πού αλλάζει η μέρα (default `Europe/Athens`) |
| `VAPID_PUBLIC_KEY` / `VAPID_PRIVATE_KEY` | Κλειδιά Web Push. Κενά = δημιουργούνται μία φορά και μένουν στη βάση |
| `COMPOSE_PROFILES` / `TUNNEL_TOKEN` | `internet` + token του Cloudflare Tunnel για πρόσβαση από το Internet |
| `SMTP_*` | Προαιρετικά, για «ξέχασα τον κωδικό» (αλλιώς ο σύνδεσμος τυπώνεται στα logs του api) |

```bash
docker compose logs -f api
docker compose exec db pg_dump -U diet diet > backup.sql
```

## Deploy στο Raspberry Pi και πρόσβαση από το Internet

Ίδια διαδικασία με το Weather Alert, με δικό του χρήστη `diet` στο Pi και SSH alias `diet-pi`:

```powershell
ssh-keygen -t ed25519 -f $HOME\.ssh\diet_deploy -C diet-deploy
# στο ~/.ssh/config:  Host diet-pi / HostName ninblack-pi.local / User diet / IdentityFile ~/.ssh/diet_deploy / IdentitiesOnly yes
scp scripts\pi-setup-deploy.sh $HOME\.ssh\diet_deploy.pub <user>@ninblack-pi.local:~/
ssh -t <user>@ninblack-pi.local "sudo sh ~/pi-setup-deploy.sh ~/diet_deploy.pub"
.\scripts\deploy.ps1          # ανεβάζει το τελευταίο commit (χρειάζεται git repo)
ssh diet-pi status / logs api / restart
```

Cloudflare Tunnel + Access (δικό του tunnel `diet-mentor` και Access application `Diet Mentor`):

```powershell
$env:CLOUDFLARE_API_TOKEN = "..."
node scripts/cloudflare-setup.mjs --hostname diet.ninblack.com --copy-emails-from bills.ninblack.com
```

Γράφει `ACCESS_TEAM_DOMAIN` / `ACCESS_AUD` στο `cloudflare-access.env` (κάνε commit, πάει με το deploy) και τυπώνει το
`TUNNEL_TOKEN`. Στο `.env` του Pi (`/home/diet/diet-mentor/.env`) μπαίνουν `APP_URL=https://diet.ninblack.com`,
`COMPOSE_PROFILES=internet`, `TUNNEL_TOKEN=…`, και μετά ξανά `scripts/deploy.ps1`. Τα push θέλουν HTTPS, άρα από το
κινητό δουλεύουν μέσω του tunnel: «Προσθήκη στην αρχική οθόνη» (υποχρεωτικό σε iPhone), άνοιγμα από εκεί, Προφίλ →
Ειδοποιήσεις → Ενεργοποίηση → Δοκιμή.

### Μεταφορά δεδομένων και backup

```powershell
.\scripts\migrate-to-pi.ps1        # μία φορά: τα δεδομένα του τοπικού docker -> Pi (μόνο όσο το Pi δεν έχει λογαριασμούς)
ssh diet-pi backup > diet.sql       # backup της βάσης του Pi όποτε θες
```

Ο λογαριασμός ταυτίζεται με το email: για να βρεις τα δεδομένα σου μέσω Cloudflare Access, το email του Access
πρέπει να είναι το ίδιο με αυτό που έκανες εγγραφή τοπικά.

## Ανάπτυξη (χωρίς docker)

```bash
docker compose up -d db                       # μόνο η βάση
cd api && npm install && npm run dev          # http://localhost:4000
cd web && npm install && npm run dev          # http://localhost:5173, proxy του /api στο 4000
cd api && npm test                            # tests υπολογισμών
```

## API (σύνοψη)

| Method | Path | Περιγραφή |
|---|---|---|
| POST | `/api/auth/signup` · `/login` · `/access` · `/forgot` · `/reset` | Λογαριασμός |
| GET/PATCH | `/api/auth/me` | Προφίλ λογαριασμού |
| GET/PUT | `/api/profile` | Φύλο, ημερομηνία γέννησης, ύψος, δραστηριότητα (+ προαιρετικά το σημερινό βάρος) |
| GET/POST | `/api/weights` · DELETE `/api/weights/:day` | Ζυγίσεις (μία ανά ημέρα) |
| GET | `/api/entries?day=` | Ημερολόγιο φαγητού μιας μέρας |
| POST/PUT/DELETE | `/api/entries` · `/api/entries/:id` | Καταχώριση φαγητού |
| GET | `/api/foods?q=` | Τα δικά σου φαγητά, πιο συχνά πρώτα |
| GET/POST | `/api/diets` | Δίαιτες με τα στατιστικά τους / έναρξη |
| POST | `/api/diets/:id/end` | Τέλος δίαιτας (προαιρετικά με τελικό βάρος) |
| PATCH/DELETE | `/api/diets/:id` | Αλλαγή / διαγραφή δίαιτας |
| GET/POST/DELETE | `/api/push/key` · `/api/push/subscribe` · `/api/push/test` | Web Push: κλειδί, εγγραφή συσκευής, δοκιμή |
| GET/PUT | `/api/notifications` · GET `/api/notifications/history` | Ρυθμίσεις ειδοποιήσεων, τι στάλθηκε |
| GET | `/api/summary` | Θερμίδες, σήμερα, ελλείμματα, γλυκογόνο, τρέχουσα δίαιτα, κίνητρο |

Όλα τα endpoints εκτός των auth απαιτούν header `Authorization: Bearer <token>`.
